# Leonin jednorog

3D igrica s jednorogom i zmajem Straškom za Leonu (Three.js).

- Igraj: https://markofrankovic-afk.github.io/jednorog/
- `index.html` je gotova igra (jedna datoteka, radi i offline).
- `src/` je izvorni kod: `python3 src/build.py index.html` spaja `head.html + game.js + tail.html`.
